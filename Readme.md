# Agentic AI

> I'm sharing how to learning Agentic AI using python. If you run the project in your local development envirment follow the steps.

#### Setup:
> You must have install python in in your operation system.

```
git clone https://github.com/mbrsagor/agenticAI.git
cd agenticAI
virtualenv -p python3.14 .venv
source .venv/bin/activate
pip install -r requirements.txt
```

> THen create `.env` file and paste `OPENAI_API_KEY` and `TAVILY_API_KEY` API key values
